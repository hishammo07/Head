Most fittings' K is not a fixed number — it changes with pipe size. This form calculates it live for each line using the Crane TP-410 method: K = fT × (L/D), where L/D is a fixed equivalent-length ratio per fitting and fT is the fully-turbulent friction factor computed from that line's own diameter and roughness. So the same elbow gets a smaller K on a wide line than on a narrow one. Every K field is still a plain editable number — type over it to lock in a manual value (it stops auto-updating for that row until you pick a different fitting type).

A few fittings use a fixed K instead, since they're not well represented by the L/D method: Sharp Entrance = 0.5, Exit = 1.0, Sudden Contraction = 0.3, Sudden Expansion = 0.5.

Other assumptions: water at 20°C (kinematic viscosity ν = 1.004×10-6 m²/s), g = 9.81 m/s². Darcy-Weisbach uses the explicit Swamee-Jain equation for the friction factor (f = 64/Re for laminar flow, Re < 2300). This is an estimation tool for general engineering use — for critical designs, verify values against a recognized reference such as Crane TP-410 or your local design code.

Pipe dimensions (outer/inner diameter) are taken from standard manufacturer catalogs: UPVC pressure pipe (6 / 10 / 16 bar), HDPE (SDR11 / SDR7.4 / SDR6), and ANSI Schedule 40 / Schedule 80. Flow rate = cross-sectional area (from the pipe's actual inner diameter) × velocity — the same relationship used throughout the Pipe Head Loss tab.
